# Site da Blink Estética Automotiva

Antes de qualquer mudança, leia `docs/PROJETO-BLINK.md`: ele traz os dados
confirmados da empresa, as regras do projeto (sem imagens de IA generativa,
sem inventar informações, acessibilidade para público mais velho) e as
pendências. Atualize esse documento a cada mudança.

- Next.js 14 (App Router) + Tailwind. `npm run build` precisa passar antes de cada push.
- Dados e textos ficam em `lib/dados.js`. Não espalhe telefone, endereço ou serviço pelo código.
- Conteúdo em português do Brasil.
